# حقوقی

بخش حقوقی سامانه هوشمند آریانا — `/hoghooghi/` روی همان Worker سایت (arianaai.website).

## معماری (مهر ۱۴۰۵)

| بخش | رابط (frontend-legal) | سرور (Worker) |
|---|---|---|
| تحلیلگر آریانا | `src/pages/ContractAnalysis.tsx` | `POST /hoghooghi/api/analyze` |
| پیش‌نویس | `src/pages/DraftReview.tsx` | `POST /hoghooghi/api/draft` |
| گفت‌وگوی حقوقی | `src/pages/LegalChat.tsx` | `/hoghooghi/api/chats…` |

- کد سرور: `worker/legal.js` (مسیرها، حافظه، فایل) و `worker/legal-prompts.js` (دستورهای مدل و قالب‌های خروجی).
- مدل: **Claude Sonnet 5** (`claude-sonnet-5`)، سقف خروجی ۱۲۸ هزار توکن، ورودی تا یک میلیون توکن، تفکر تطبیقی.
- کلید: راز `ANTHROPIC_API_KEY` روی Worker — همان کلیدی که بخش تأمین و پشتیبانی هم به کار می‌برد.
- فایل‌ها: مرورگر Word/اکسل/پاورپوینت را به متن تبدیل می‌کند و فایل جریانی از Worker به **Files API انتروپیک** می‌رود
  (فایل تحلیل و پیش‌نویس یک روز می‌ماند؛ فایل گفت‌وگو تا حذف گفت‌وگو). گزارش Word در مرورگر ساخته می‌شود.
- داده: جدول‌های `legal_chats`، `legal_turns`، `legal_files`، `legal_calls` در همان D1 (خودکار ساخته می‌شوند).

### چرا نه تابع Supabase

توابع `supabase/functions/analyze-contract` و `draft-review` در پلن رایگان Supabase بعد از ۱۵۰ ثانیه بسته می‌شدند
(`shutdown reason: WallClockTime`) و تحلیل یک قرارداد بیشتر طول می‌کشد؛ کاربر پس از چند دقیقه پیام خطا می‌دید.
درخواست Worker تا وقتی مرورگر وصل است سقف زمانی ندارد و پاسخ مدل بی‌دست‌خوردگی جریان می‌یابد.
این دو تابع فقط برای سابقه در مخزن مانده‌اند و رابط کاربری دیگر صدایشان نمی‌زند.

### حافظهٔ گفت‌وگو

هر گفت‌وگو یک حافظهٔ متنی جدا دارد (`legal_chats.memory`): موضوع، اطلاعات کلیدی، خلاصهٔ هر فایل با درخواست
کاربر و نتیجه، پرسش و پاسخ‌ها، تصمیم‌ها و کارهای باز. پس از هر پاسخ، مدل «نگه‌دارندهٔ حافظه» آن را به‌روز می‌کند و
اگر از ۱۲ هزار نویسه گذشت فشرده‌اش می‌کند. تا ۳۵۰ هزار توکن، متن خام گفت‌وگو هم به مدل می‌رود (با کش پرامپت)؛
بیش از آن، نوبت‌های قدیمی بیرون می‌روند و حافظه جایشان را می‌گیرد و فایل‌هایشان تا سقف سنجاق می‌مانند.

### تست

```
node --test "backend/hoghooghi/tests/*.test.mjs"
```

تست‌ها با مدل بدلی و D1 روی node:sqlite اجرا می‌شوند؛ هزینه‌ای ندارند.

### ساخت رابط

```
cd frontend-legal && npm run build
```

خروجی `frontend-legal/dist` جای `frontend/hoghooghi` را می‌گیرد (پوشهٔ `assets` قبلی پاک و نو کپی شود).
